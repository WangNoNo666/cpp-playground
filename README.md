# 💻 C++20 在线编译器

一个仿 **CPH-NG（VS Code 插件）** 体验的在线 C++20 编译器/刷题环境：

- **CodeMirror 6** 编辑器（本地内置，零 CDN）——流畅书写、One Dark 配色、C++ 语法高亮
- **VS Code 风格多标签**：上方标签栏，可新建 / 关闭 / 双击重命名 / 多文件切换
- **F9 运行样例**：右侧测试用例面板（输入 + 期望输出），一键全部运行并逐项比对通过/失败
- **⚡ 批量编译（快）**：任意用例数都走一次编译、**一次请求跑完全部用例**（实测 4 用例从 ~18s 降到 ~5s）
- **⏱️ 评测机口径运行时间**：每个用例显示 **CPU 时间**（`clock()` 测量，同 OJ 评测口径），另附进程**峰值内存**（Linux getrusage）；单用例与自定义输入同样显示 CPU 时间，客户端总耗时单独标注
- **🪜 默认 512MB 大栈**：自动把运行栈从默认 8MB 提升到 512MB（`setrlimit`），深递归（DFS/爆搜）不再段错误
- **自定义时限**：可设单次运行时限（毫秒），**超时自动中止请求，防止卡死**（标记 ⏱ 超时）
- **代码分享**：📤 分享弹窗自动生成**超短链接**（`.../?w=xxxx`，仅 ~65 字符，经 Wandbox 存储，微信发送不被截断）；生成失败时回退到 LZ/Base64 压缩链接（长代码缩短 3~4 倍）；另有「复制代码」兜底
- **代码模板（📋）**：内置 6 个竞赛模板（C++20 快速模板 / 快读快写 / 并查集 / 线段树 / Dijkstra / 快速幂），可一键**插入光标处**或**用模板新建文件**；也支持**保存当前代码为自定义模板**（存 localStorage，可删除）
- **大样例本地上传**：每个用例有"上传"按钮，或直接把 `.in/.out` 文件**拖到用例输入/期望框**上自动填入
- **拖拽本地代码**：`.cpp/.h/.txt` 拖进页面自动新建标签（修复了编辑器拦截拖拽的问题）
- **快捷键齐全**：F9 运行样例 · Ctrl+Enter 自定义输入 · Ctrl+S 保存 · Ctrl+N 新建 · Ctrl+W 关闭 · Ctrl+O 打开 · Tab 缩进 · Ctrl+/ 注释 · Ctrl+F 查找
- **本地持久化**：代码、用例、后端/编译器/时限设置自动保存（localStorage）
- **C++20 支持**：默认 `-std=c++20 -O2`，可切换 GCC 最新 / GCC 13 / Clang 等编译器

**在线使用：https://wangnono666.github.io/cpp-playground/**

## 编译后端

| 后端 | 说明 |
|---|---|
| Wandbox（默认） | 免费公开 API，支持 C++20/23，稳定 |
| Compiler Explorer | 自动兜底（Wandbox 不可用时） |

> 编译在远端公共服务器进行，代码会上传至第三方（Wandbox / Godbolt），**不要粘贴敏感信息**。
> 批量模式展示真实的进程内每用例耗时与峰值内存；逐用例模式（1 个用例）显示客户端总耗时。

## 快捷键

| 快捷键 | 功能 |
|---|---|
| `F9` | 编译并运行全部测试用例（比对期望输出） |
| `Ctrl+Enter` | 用「自定义输入」框的内容运行当前代码 |
| `Ctrl+S` | 下载当前文件 |
| `Alt+N` / `Alt+W` / `Alt+O` | 新建 / 关闭标签 / 打开本地文件（**可靠键**） |
| `Ctrl+N` / `Ctrl+W` / `Ctrl+O` | 同上（尽力而为；Chrome/Edge 将 Ctrl+N/W 保留为浏览器快捷键，可能被浏览器接管） |
| `Tab` / `Shift+Tab` | 缩进 / 反缩进 |
| `Ctrl+/` | 行注释 / 取消注释 |
| `Ctrl+F` | 查找替换 |

> **为什么用 Alt 组合**：Chrome/Edge 将 `Ctrl+W`（关标签页）、`Ctrl+N`（新窗口）、`Ctrl+T` 列为浏览器保留快捷键，网页无法用 preventDefault 拦截。因此：
> - `Ctrl+W`：尽力拦截；若浏览器仍要关闭，`beforeunload` 会弹出确认框，点「取消」即可留在页面（代码标签已关闭）
> - 新建/打开请优先用 **Alt+N / Alt+O**；标签栏也有 ＋、📂、✕ 按钮

## 用例来源

- 手动「＋ 添加用例」（输入 + 期望输出）
- 每个用例的「上传」按钮，或直接把 `.in/.out` 文件拖到用例输入/期望框上自动填入

## 文件结构

```
cpp-playground/
├── index.html          # 应用本体（HTML/CSS/JS 内联）
├── editor.bundle.js    # CodeMirror 6 打包产物（esbuild 单文件）
├── README.md
└── cpp-smoke.js        # 冒烟测试（node cpp-smoke.js，含真实编译与网络）
```

## 本地运行

双击 `index.html` 即可（需与 `editor.bundle.js` 同目录），或 `npx serve` / 任意静态服务器。

## 开发说明

`editor.bundle.js` 由 CodeMirror 6 + `@codemirror/lang-cpp` + `@codemirror/theme-one-dark` 经 esbuild 打包（IIFE 单文件），无运行时 CDN 依赖。
